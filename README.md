# 오늘 메뉴 추천 - 랜덤 메뉴 추천기 🍽️

매일 고민되는 식사 메뉴! 한식, 중식, 일식, 양식, 분식/패스트푸드, 아시안/기타 카테고리별로 맛있는 메뉴를 랜덤으로 추천해 주는 웹 애플리케이션입니다.

## ✨ 주요 기능
- **카테고리별 필터링**: 전체, 한식, 중식, 일식, 양식, 분식/패스트푸드, 아시안/기타
- **슬롯머신 롤링 애니메이션**: 흥미진진한 메뉴 추첨 효과
- **추천 결과 카드**: 메뉴 사진 및 추천 이유, 특징 제공
- **주변 식당 찾기 바로가기**: 네이버 지도 / 카카오맵 연동
- **축하 효과**: 폭죽(Confetti) 애니메이션

## 🚀 기술 스택
- HTML5
- CSS3 (Vanilla CSS, Glassmorphism & Animations)
- JavaScript (ES6+)

## 💻 실행 방법
별도의 설치 없이 `index.html` 파일을 웹 브라우저에서 열면 바로 실행됩니다.
